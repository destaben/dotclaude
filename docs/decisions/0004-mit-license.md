# 0004 — MIT license for this repo

- Date: 2026-10-17
- Status: accepted, pending final confirmation

## Context
The repo is public. A license was needed; MIT was the stated default absent
other instructions.

## Decision
Licensed under MIT (see `LICENSE`), copyright held by "dotclaude contributors"
rather than a named individual, since the repo is public and personal names
are kept out of tracked files per `CLAUDE.md`.

## Consequences
Items adopted from `awesome-copilot` (also MIT — see `docs/references.md`)
are compatible without extra attribution requirements beyond what's already
recorded there. This is listed as an open question in the final report in
case a different license was actually intended.
